# Austin Jackson — Personal Website

Static personal site for sports journalist Austin Jackson. Plain HTML/CSS, no build step, hosted on GitHub Pages.

## Structure
- `index.html` — the whole site (About, Featured Work, Clips, Resume, Contact)
- `assets/styles.css` — styles
- `assets/` — put the headshot (`headshot.jpg`) and resume PDF here

## Placeholders
Anything still to fill in is marked with a `<!-- PLACEHOLDER -->` comment and a dashed `placeholder` class
(which shows a light striped highlight in the browser). Remove the class once real content is in.

## Preview locally
Open `index.html` in a browser, or run `python3 -m http.server` and visit http://localhost:8000.

## Deploy
Repo Settings → Pages → Source: "Deploy from a branch", Branch: `main` / root.
